# MedAlert — لوحة الصحة والسلامة

مشروع طلابي. نظام بلاغات إصابات وإغماء ونقص مستلزمات إسعاف، بواجهة عربية كاملة.
**PHP 8.0+ · تخزين في ملف JSON · بدون قاعدة بيانات · بدون Composer.**

---

## التشغيل

### الطريقة الأسرع — سيرفر PHP المدمج

```bash
php -S localhost:8000 index.php
```

ثم افتح <http://localhost:8000>

> ⚠️ **اكتب `index.php` في نهاية الأمر.** هذا يجعل كل الطلبات تمرّ عبر الملف،
> فيمنع أي شخص من تنزيل `data.json` مباشرةً (وهو يحوي هاشات كلمات المرور).
> بدونها، `php -S localhost:8000` سيخدم `data.json` لأي زائر.

### مع XAMPP / WAMP / Laragon

انسخ المجلد إلى `htdocs` ثم افتح <http://localhost/medalert-php/>
ملف `.htaccess` المرفق يتكفّل بالحماية على Apache.

### مع Nginx

`.htaccess` لا يعمل على Nginx. أضف داخل كتلة `server`:

```nginx
location ~* \.(json|md|log)$ { deny all; }
location ^~ /uploads/ { location ~ \.php$ { deny all; } }
```

| الاسم | المستخدم | كلمة المرور | الصلاحية |
|---|---|---|---|
| منسّق السلامة | `admin` | `admin123` | admin |
| ممرضة العيادة | `nurse` | `nurse123` | admin |
| مشرف مبنى أ | `staff` | `staff123` | staff |

**الفرق بين الصلاحيتين:**

| الإجراء | admin | staff |
|---|:--:|:--:|
| تسجيل بلاغ جديد | ✅ | ✅ |
| عرض السجل والحقائب والطوارئ | ✅ | ✅ |
| إغلاق بلاغ | ✅ | ❌ |
| إعادة تعبئة صنف ناقص | ✅ | ❌ |

> 🔐 **لتغيير كلمة مرور:** احذف `data.json` وأعد إنشاءه من النسخة الأصلية،
> أو غيّر قيمة `pass` إلى `"pass_plain": "كلمتك"` واحذف `"seeded": true`.
> عند أول تشغيل يشفّرها `index.php` تلقائيًا بـ `password_hash()` ويحذف النص الصريح.

## الملفات

```
medalert-php/
├── index.php          ← التطبيق كامل: الدخول، الصلاحيات، الصفحات الخمس، الـ API
├── data.json          ← البيانات: المستخدمون، البلاغات، الحقائب
├── .htaccess          ← منع تنزيل data.json (Apache)
├── uploads/
│   └── .htaccess      ← منع تنفيذ أي سكربت داخل مجلد الصور
└── README.md
```

`uploads/` يُنشأ تلقائيًا عند أول رفع صورة إن لم يكن موجودًا.

## الحماية المطبَّقة

| الخطر | الإجراء |
|---|---|
| كلمات مرور مكشوفة | `password_hash()` بـ bcrypt — لا تُخزَّن أبدًا كنص صريح |
| CSRF | توكن في كل نموذج POST، يُقارَن بـ `hash_equals()` |
| XSS | `htmlspecialchars()` بـ `ENT_QUOTES` على كل مخرجات المستخدم |
| رفع ملف خبيث | تحقق بـ `getimagesize()` من المحتوى الفعلي لا الامتداد + اسم عشوائي + منع التنفيذ |
| سرقة الجلسة | `session_regenerate_id(true)` عند الدخول + `HttpOnly` + `SameSite=Lax` |
| تخمين كلمة المرور | تهدئة ١٢٠ ثانية بعد ٦ محاولات فاشلة |
| كشف وجود المستخدم | التحقق يتم دائمًا من هاش، حتى لو المستخدم غير موجود |
| تلف ملف البيانات | كتابة ذرّية: ملف مؤقت ثم `rename()` |
| إعادة إرسال النموذج | نمط PRG — كل POST يتبعه تحويل 303 |

### ما **لم** يُطبَّق — اعرفه قبل أي استخدام حقيقي

- **لا HTTPS.** الجلسة وكلمة المرور تمرّان كنص صريح على HTTP.
- **لا تزامن حقيقي.** الكتابة ذرّية لكنها **آخر-كاتب-يفوز**؛ كتابتان متزامنتان قد تُلغي إحداهما الأخرى. مقبول لمشروع طلابي، غير مقبول لعشرات المستخدمين.
- **لا سجل تدقيق كامل.** نسجّل من أغلق البلاغ ومتى، ولا نسجّل التعديلات الأخرى.
- **`data.json` ليس مشفّرًا.** من يصل للقرص يقرأ كل شيء عدا كلمات المرور.
- **لا استرجاع كلمة مرور، ولا إدارة مستخدمين من الواجهة.**

## متطلبات

- PHP **8.0** أو أحدث (يستخدم `match` و `str_contains`)
- امتداد **mbstring** مفعّل (لدوال `mb_substr` / `mb_strtolower` مع العربية)
- صلاحية كتابة على مجلد المشروع (لحفظ `data.json` و `uploads/`)

للتحقق:

```bash
php -v && php -m | grep -i mbstring
```

## إعادة التهيئة

أعد `data.json` إلى نسخته الأصلية (بـ `"seeded": false`) ثم حدّث الصفحة —
سيعيد `index.php` توليد التواريخ وتشفير كلمات المرور من جديد.

لمسح الصور المرفوعة: احذف محتويات `uploads/` عدا `.htaccess`.

## تنبيه

جميع البيانات تجريبية ولا تمثّل حوادث حقيقية.

ولا عن الاتصال بخدمات الطوارئ.
